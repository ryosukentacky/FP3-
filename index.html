01
FP基礎

FPが守るべきこと

A 要点

顧客の利益を優先し、秘密を守り、必要な説明を行い、自分の専門範囲を越える業務は専門家につなぐことが基本です。

B 詳しい解説

FPは顧客のお金や家族など重要な情報を扱います。そのため、顧客利益の優先、守秘義務、説明責任が重要です。また、税務・法律など他の専門資格の独占業務に踏み込まず、必要なら税理士・弁護士などの専門家へつなぎます。一般的な制度説明と、資格が必要な個別具体的な専門業務を区別するのがポイントです。

C イメージ理解

FPは「何でも自分で解決する人」ではなく、家計全体を見ながら正しい専門家へ案内する総合案内役、と考えると分かりやすいです。

D 具体例

相続税について制度の一般的な仕組みを説明することはできますが、個別の税務相談・税務代理・税務書類作成などは税理士の専門領域になります。

理解確認

①顧客の秘密を第三者へ自由に話してよい？ → いいえ。 ②専門外の個別業務は？ → 専門家につなぐ。 ③FPが優先するものは？ → 顧客の利益。

30秒復習

顧客第一／秘密を守る／きちんと説明／専門領域を越えない。

一文で覚える

顧客第一・秘密を守る・きちんと説明・越境せず専門家へ。

02
ライフプラン

キャッシュフロー表

A 要点

家計の収入・支出・年間収支・貯蓄残高などを年ごとに予測し、将来のお金の流れを見る表です。

B 詳しい解説

基本は「収入－支出＝年間収支」。さらに「前年の貯蓄残高＋年間収支＝その年の貯蓄残高」とつなげます。将来の収入や支出を変動率で見積もる場合は、現在額×(1＋変動率)^年数という考え方を使います。

C イメージ理解

個人バランスシートが家計の「写真」なら、キャッシュフロー表は家計のお金が年ごとに動く「動画」です。

D 具体例

前年貯蓄500万円、今年の収入500万円、支出400万円なら年間収支は＋100万円。単純化すれば今年末の貯蓄残高は600万円です。

理解確認

①収入500万円・支出450万円の年間収支は？ → ＋50万円。 ②何を年ごとに見る？ → 収入・支出・貯蓄残高など。 ③写真に近いのは？ → 個人バランスシート。

30秒復習

収入－支出＝年間収支。前年貯蓄＋年間収支＝現在の貯蓄残高。

一文で覚える

キャッシュフロー表は、将来のお金の流れを年ごとに見る表。

03
ライフプラン

可処分所得

A 要点

収入から税金と社会保険料を差し引いた、実際に家計で使えるお金です。

B 詳しい解説

FP学習では「年収－所得税－住民税－社会保険料」で考えます。食費や家賃などの生活費を引いた後の金額ではありません。

C イメージ理解

給与という大きな袋から、税金と社会保険料を先に取り出し、家計の手元に残った袋が可処分所得です。

D 具体例

年収500万円、所得税10万円、住民税20万円、社会保険料70万円なら、可処分所得は420万円です。

理解確認

①生活費を引く？ → 引かない。 ②主に何を引く？ → 所得税・住民税・社会保険料。 ③その後何に使う？ → 生活費・貯蓄など。

30秒復習

年収 → 税・社会保険料を引く → 可処分所得 → 支出 → 年間収支。

一文で覚える

可処分所得＝年収－所得税－住民税－社会保険料。

04
6係数

終価係数

A 要点

今ある一括資金を一定利率で運用したとき、将来いくらになるかを求める係数です。

B 詳しい解説

現在額×終価係数＝将来額。複利で増えるため、単純に利息を足すのではなく、利息にも利息がつく効果を含めます。

C イメージ理解

「今」のお金を未来へ飛ばす係数です。現在 → 将来。

D 具体例

100万円を年3％で5年間運用し、終価係数が1.159なら、100万円×1.159＝115.9万円。

理解確認

①スタートは？ → 現在の一括資金。 ②求めるものは？ → 将来額。 ③逆方向は？ → 現価係数。

30秒復習

今あるお金／一括／未来へ。

一文で覚える

終価係数＝今あるお金を未来へ飛ばす係数。

05
6係数

現価係数

A 要点

将来必要な金額を得るために、今いくら一括で用意すればよいかを求める係数です。

B 詳しい解説

将来額×現価係数＝現在必要額。将来の金額を現在価値へ割り戻します。終価係数とは逆方向です。

C イメージ理解

未来にあるお金を現在まで引き戻すイメージです。将来 → 現在。

D 具体例

5年後に100万円必要で、年3％・現価係数0.863なら、100万円×0.863＝86.3万円を現在用意するイメージです。

理解確認

①将来100万円欲しい。今一括でいくら？ → 現価係数。 ②逆方向は？ → 終価係数。 ③毎年積み立てる額を求めるなら？ → 減債基金係数。

30秒復習

未来の目標額 → 今の一括資金。

一文で覚える

現価係数＝未来に必要なお金を現在まで引き戻す係数。

06
6係数

年金終価係数

A 要点

毎年同じ金額を積み立てた場合、将来いくらになるかを求める係数です。

B 詳しい解説

毎年の積立額×年金終価係数＝将来額。各年の積立金は運用期間が異なるため、その運用効果もまとめて計算します。「年金」は公的年金専用という意味ではなく、毎期一定額のお金の流れを表します。

C イメージ理解

毎年貯金箱に同じ金額を入れ、それぞれを運用しながら最後の時点へ集めます。毎年 → 将来。

D 具体例

毎年100万円、年3％で5年間積み立て、係数が5.309なら、100万円×5.309＝530.9万円。

理解確認

①毎年50万円を積み立て10年後いくら？ → 年金終価係数。 ②今500万円を一括運用なら？ → 終価係数。 ③逆方向は？ → 減債基金係数。

30秒復習

毎年の積立額 → 将来の合計額。

一文で覚える

年金終価係数＝毎年コツコツ積み立てたら最後にいくら？

07
6係数

減債基金係数

A 要点

将来の目標額を作るために、毎年いくら積み立てればよいかを求める係数です。

B 詳しい解説

将来必要額×減債基金係数＝毎年の積立額。運用益を考慮するため、目標額を単純に年数で割る場合とは異なります。年金終価係数の逆方向です。

C イメージ理解

未来のゴール金額から逆算して、毎年入れるべき金額を決めます。将来 → 毎年。

D 具体例

5年後に500万円必要で係数が0.188なら、500万円×0.188＝毎年94万円を積み立てるイメージです。

理解確認

①10年後1,000万円、毎年いくら積立？ → 減債基金係数。 ②毎年50万円、10年後いくら？ → 年金終価係数。 ③今一括でいくら必要？ → 現価係数。

30秒復習

将来の目標額 → 毎年の積立額。

一文で覚える

減債基金係数＝将来の目標額から毎年の積立額を逆算する係数。

08
6係数

資本回収係数

A 要点

今ある一括資金を運用しながら取り崩す場合、毎年いくら受け取れるかを求める係数です。

B 詳しい解説

現在額×資本回収係数＝毎年の受取額。元本だけでなく残高の運用も考慮しながら一定期間で取り崩す考え方です。

C イメージ理解

大きな一つの資金を、毎年受け取る小さなお金へ分けていきます。現在 → 毎年。

D 具体例

現在1,000万円、資本回収係数0.117なら、1,000万円×0.117＝毎年117万円。

理解確認

①今1,000万円を10年間取り崩すと毎年いくら？ → 資本回収係数。 ②将来1,000万円のため毎年いくら積立？ → 減債基金係数。 ③逆方向は？ → 年金現価係数。

30秒復習

今ある一括資金 → 毎年の受取額。

一文で覚える

資本回収係数＝今あるまとまったお金を毎年いくら受け取れるかに変換する係数。

09
6係数

年金現価係数

A 要点

将来、毎年一定額を受け取るために、現在いくら一括で必要かを求める係数です。

B 詳しい解説

毎年の受取額×年金現価係数＝現在必要額。将来の各年の受取額を現在価値に割り戻してまとめます。資本回収係数とは逆方向です。

C イメージ理解

未来に毎年並んでいるお金を全部「今」に引き寄せ、一つの資金にまとめます。毎年 → 現在。

D 具体例

今後5年間毎年100万円を受け取り、年金現価係数が4.580なら、現在必要額は100万円×4.580＝458万円。

理解確認

①今後10年間毎年100万円欲しい。今いくら？ → 年金現価係数。 ②今1,000万円から毎年いくら？ → 資本回収係数。 ③毎年積立して将来いくら？ → 年金終価係数。

30秒復習

毎年の受取額 → 現在の一括資金。

一文で覚える

年金現価係数＝毎年○万円欲しい。そのために今いくら必要？

10
教育資金

こども保険（学資保険）

A 要点

子どもの進学などに必要な教育資金を計画的に準備するための保険です。

B 詳しい解説

保険料を払い、契約で定めた進学時期などに祝金・満期保険金等を受け取る商品があります。契約者である親などが死亡・高度障害状態になった場合、契約内容により以後の保険料払込みが免除される仕組みもあります。

C イメージ理解

「教育費用の貯金箱」に保障機能を組み合わせたイメージです。

D 具体例

子どもが0歳のときに加入し、18歳の大学進学時に満期保険金等を受け取るよう準備します。途中で契約者に万一のことがあった場合、契約に応じて保険料払込免除などが機能します。

理解確認

①主目的は？ → 教育資金準備。 ②親に万一なら？ → 契約により払込免除など。 ③必ず元本以上？ → いいえ。

30秒復習

教育資金＋保障。途中解約や商品条件によって元本割れする場合もある。

一文で覚える

こども保険＝教育資金を準備しながら、親の万一にも備える保険。

11
教育資金

教育一般貸付

A 要点

日本政策金融公庫が扱う教育費向けの公的融資で、一般に「国の教育ローン」と呼ばれます。

B 詳しい解説

進学・在学に必要な教育費を支える融資です。基本的には保護者などが借りる点が、学生本人が借りる貸与型奨学金との重要な違いです。

C イメージ理解

大学進学でまとまった教育費が必要になったとき、保護者側から教育費を支えるローンです。

D 具体例

入学金・授業料・教材費・受験費用・自宅外通学の住居費など、対象となる教育関連費用に利用できます。

理解確認

①別名は？ → 国の教育ローン。 ②代表的な機関は？ → 日本政策金融公庫。 ③主に誰が借りる？ → 保護者など。

30秒復習

教育一般貸付 → 国の教育ローン → 日本政策金融公庫 → 主に保護者。

一文で覚える

教育一般貸付＝日本政策金融公庫から主に保護者が借りる国の教育ローン。

12
教育資金

奨学金制度

A 要点

学生の進学・修学を経済的に支援する制度で、代表例に日本学生支援機構（JASSO）の奨学金があります。

B 詳しい解説

大きく給付型と貸与型があります。給付型は原則返済不要。JASSOの貸与型では、第一種は無利子、第二種は有利子です。採用には学力・家計など所定の基準があります。

C イメージ理解

「もらう支援」が給付型、「借りる支援」が貸与型。貸与型では学生本人が借り、返還します。

D 具体例

大学進学費用が不足する学生がJASSOの貸与型奨学金を利用し、卒業後などに本人が返還していくケースです。

理解確認

①返済不要は？ → 給付型。 ②第一種は？ → 無利子。 ③第二種は？ → 有利子。

30秒復習

給付＝返さない／貸与＝返す／第一種＝無利子／第二種＝有利子。

一文で覚える

奨学金＝給付型は返さない、貸与型は返す。第一種は無利子、第二種は有利子。

13
住宅ローン

住宅ローンの金利タイプ

A 要点

住宅ローンの代表的な金利タイプは、固定金利型・変動金利型・固定金利期間選択型です。違いは「金利がいつ変わる可能性があるか」です。

B 詳しい解説

固定金利型は一定期間または全期間で金利を固定します。変動金利型は市場金利などに応じて適用金利が見直されます。固定金利期間選択型は当初3年・5年・10年など一定期間の金利を固定し、固定期間終了後にその時点の条件に基づいて金利タイプを選択するなどの対応をします。

C イメージ理解

固定＝🔒────────／変動＝📈📉📈📉／期間選択＝🔒🔒🔒｜📈📉。固定期間選択型は「最後まで固定」ではなく「一定期間だけ固定」です。

D 具体例

10年固定を選んだ場合、当初10年間は固定。その後は固定期間が終了し、その時点の金利状況や商品条件に基づいて見直されます。

理解確認

①全期間安定させたい？ → 全期間固定金利型。 ②市場金利の影響を受ける？ → 変動金利型。 ③最初の10年だけ固定？ → 固定金利期間選択型。

30秒復習

固定＝安定／変動＝金利に合わせて動く／期間選択＝最初の一定期間だけ固定。

一文で覚える

固定＝ずっと安定、変動＝金利に合わせて動く、期間選択＝最初だけ固定。
